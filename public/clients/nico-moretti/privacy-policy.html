Privacy Policy

Last updated: 27 October 2026

About this policy

This policy explains how Nico Moretti, based in Adelaide, South Australia, handles personal information collected on nicomoretti.au. It is written in plain English for the Australian Privacy Principles in the Privacy Act 1988 (Cth), in particular APP 1 (an open and transparent policy), APP 5 (telling you when information is collected) and APP 8 (sending information outside Australia). It is not legal advice.

The website does not publish an ABN, a phone number, or an email address. To ask about your information, use the inquiry form on the contact section of the website and say that your message is about privacy.

The website chat

The site has a chat called Sofia. Sofia is an AI assistant. The replies are not typed by a person.

When you send a message, this is what happens.

  • Your browser keeps the chat on this device, under the name nico-chat-history. It keeps the last 50 messages. The chat code does not set an end date. That copy stays until you clear this site's saved data, or your browser removes it.
  • The whole chat kept in the browser, up to those 50 messages, is sent to this website's server with each new message. That server runs in Sydney.
  • The server sends those messages to DeepSeek so DeepSeek can write the reply. The call goes to api.deepseek.com and uses DeepSeek's deepseek-v4-flash model. DeepSeek is Hangzhou DeepSeek Artificial Intelligence Co., Ltd., a company in China. DeepSeek's privacy policy says it stores personal data in the People's Republic of China. Sending your messages there is a disclosure outside Australia under APP 8.
  • The chat route does not send your messages to OpenAI, and it does not create embeddings. It does not store the chat in Redis.

Do not type sensitive information into the chat. That includes passwords, payment card numbers, bank details, tax file numbers, identity document numbers, and health information. What you type is sent to DeepSeek in China, and a copy may be stored outside Australia as described below.

What we store from the chat, and for how long

When the site's database is connected, the server keeps a copy of your latest message and Sofia's reply in Supabase. That project is in Tokyo, Japan, which is also outside Australia. The copy includes the text (shortened if it is longer than 20,000 characters), the model name, and the token counts for that reply. It is labelled as the Nico Moretti chat. The route does not send a thread id, so each reply is stored as its own record. Earlier messages in the same chat are sent again to DeepSeek with your next message. They are not written again unless they were the latest message on an earlier reply. The chat record does not include your IP address.

If that database is not connected, the chat still replies and no server copy is stored. The copy in your browser is separate.

A daily job is set to delete these chat records after 90 days.

The inquiry form

The contact form collects your name, email address, phone number if you give one, your message, the duration you select, and the event type. It is sent to this website's inquiry service.

The inquiry is saved in an Upstash Redis list. The code that saves it does not set a deletion date, and it does not name the country where that list is stored. A copy is emailed to the business through Resend. The code does not name the country where Resend stores or sends that email. If a Telegram channel is configured for this business, the same inquiry is also sent to Telegram at api.telegram.org. Telegram is outside Australia. The code does not name the country where Telegram keeps the message.

The chat and the inquiry form are separate. Typing in the chat does not fill in the form.

Why we collect it

We collect this information to answer questions about Nico Moretti's services, to reply to an inquiry, and to run the website chat. We do not sell personal information.

Access, correction and complaints

You can ask for access to the personal information we hold about you, or ask us to correct it, by using the inquiry form. Say that the message is about privacy, and include the email address you used so we can find the right record. We may need to check that you are the person the information is about before we release it.

If you are unhappy with how we handle your information, contact us the same way first. If you are not satisfied with the response, you can complain to the Office of the Australian Information Commissioner (OAIC):
