Ask a legal research question in the composer and Lex searches, reads sources and writes an answer with Conclusions and Sources. Each answer has Copy and Export to Word, and Draft to start a document from it. Use New research to start a fresh thread. Threads can be renamed, moved into a project by dragging, or opened from the sidebar. Email research thread sends all questions and answers, with citations. If an answer looks wrong, use Flag an issue with this answer under it.
